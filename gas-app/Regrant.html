Restore Drive Access

Day Planner can only edit Drive files you have handed to it. Moving the script to its new Google Cloud project dropped that for the files below, so saves to them fail.

  1. Click Choose files.
  2. In the Day Planner folder tab, Shift-click to select every item marked No, then click Select.
  3. Open the picker again, go to the Folders tab, select the Day Planner folder itself, then click Select.
