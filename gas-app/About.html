User Guide & Features Overview

1. Purpose & Product Vision

The Day Planner bridges timeless paper day planner productivity methodology with real-time Google Workspace cloud capabilities.

2. Google Drive Folder Setup

lock Privacy & Security

To protect your privacy, Day Planner CANNOT read or write any existing files across your Google Drive.

Google Drive Folder Link Instructions:
  1. Create a dedicated folder named Day Planner in your Google Drive (e.g. https://drive.google.com/drive/u/0/folders/1N2WRrFmtsAWKgqeaFIj9HtiQ2wupFEk0).
  2. The application securely links your folder ID to store your planner notes and documents.
  3. All daily notes documents and monthly subfolders are created under /Day Planner/.

4. User Instructions & Workflow Guide

format_list_bulleted A1–C9 Task Prioritization & Status Codes

Tasks are categorized into Priority Groups (A = Urgent, B = Important, C = Low) with sequence numbers (1–9). Click the status box to cycle: fiber_manual_record (Open) arrow_forward check (Completed) arrow_forward east (Forwarded) arrow_forward close (Canceled) arrow_forward Ⓓ (Delegated).

move_item Monthly Master Task Transfer

Open the Master Task List tab to view categorized monthly objectives (Work, Personal, Financial, Projects). Click Move to Today to assign an active [A1] priority tag and transfer it directly to today's task list.

tag Automated Monthly Indexing (#index)

Tag key meeting outcomes or decisions in your daily notes using #index [Topic] Summary. The Monthly Index automatically aggregates and links these entries chronologically.

sync 2-Way Workspace Sync

Click 2-Way Sync in the top header bar to reconcile tasks and calendar appointments. Background triggers automatically run every 5 minutes.

5. Desktop & Mobile Setup ("Open as Window")

Day Planner is designed as a standalone, 100% cloud-hosted web application with zero external dependencies. While it runs securely inside Google Apps Script, you can run it borderless and distraction-free as a dedicated desktop or mobile app window:

desktop_windows Google Chrome (Desktop)

Open the Day Planner web app in Chrome. Click the menu icon (⋮) in the top-right corner → Save and share (or More tools) → Create shortcut.... Ensure "Open as window" is checked, then click Create. You can pin the shortcut to your Windows Taskbar or macOS Dock for instant access.

laptop_mac Microsoft Edge (Desktop)

Open the Day Planner web app in Edge. Click the menu icon (…) in the top-right corner → Apps → Install this site as an app. Keep the name as Day Planner and click Install. Edge will launch the planner in its own native app frame.

smartphone Mobile Devices (iOS Safari & Android Chrome)

iOS (Safari): Tap the Share button at the bottom of the screen, scroll down, and select Add to Home Screen.
Android (Chrome): Tap the menu icon (⋮) at the top-right and select Add to Home screen or Install app.
