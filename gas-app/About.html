1. Purpose & Product Vision

The Day Planner bridges the timeless, battle-tested productivity methodology of classic paper day planners with real-time Google Workspace cloud capabilities. Designed for solo power users who require structured discipline, it provides a high-efficiency single-page digital binder interface.

2. Google Workspace Integration Matrix

Google Service Apps Script API Integration Role
Google Calendar CalendarApp / API v3 Renders 07:00 AM – 07:00 PM appointment schedule grid, event details modal, Google Meet launcher, and 2-way workspace sync.
Google Tasks Tasks API v1 Manages daily [A1-C9] prioritized tasks and Monthly Master Task Lists with 1-click transfer.
Google Docs DocumentApp Backs the daily notes pane with Google Docs stored in /Day Planner/YYYY/MM/; scans #index decision tags.
Google Drive DriveApp Organizes folder hierarchy under /Day Planner/YYYY/MM/ using strict least-privilege drive.file scope.

3. User Instructions & Workflow Guide

format_list_bulleted A1–C9 Task Prioritization & Status Codes

Tasks are categorized into Priority Groups (A = Urgent, B = Important, C = Low) with sequence numbers (1–9). Click the status box to cycle: • (Open) → ✓ (Completed) → → (Forwarded) → X (Canceled) → G/✓ (Delegated).

move_item Monthly Master Task Transfer

Open the Master Task List tab to view categorized monthly objectives (Work, Personal, Financial, Projects). Click Move to Today to assign an active [A1] priority tag and transfer it directly to today's task list.

tag Automated Monthly Indexing (#index)

Tag key meeting outcomes or decisions in your daily notes using #index [Topic] Summary. The Monthly Index automatically aggregates and links these entries chronologically.

sync 2-Way Workspace Sync

Click 2-Way Sync in the top header bar to reconcile tasks and calendar appointments. Run setup2WaySyncTrigger() once in Google Apps Script to enable 10-minute background triggers.
