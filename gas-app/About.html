1. Purpose & Product Vision

The Day Planner bridges timeless paper day planner productivity methodology with real-time Google Workspace cloud capabilities. Designed for solo power users who require structured discipline, it provides a high-efficiency single-page digital binder interface under strict least-privilege security permissions.

2. Least-Privilege Security & Google Drive Folder Setup

lock Strict Per-File Security Scope (drive.file)

To protect your privacy, Day Planner relies strictly on https://www.googleapis.com/auth/drive.file. This scope ensures the application CANNOT read or write any existing files across your Google Drive.

Google Drive Folder Link Instructions:
  1. Create a dedicated folder named Day Planner in your Google Drive (e.g. https://drive.google.com/drive/u/0/folders/1N2WRrFmtsAWKgqeaFIj9HtiQ2wupFEk0).
  2. The application records your folder ID (1N2WRrFmtsAWKgqeaFIj9HtiQ2wupFEk0) in your account's UserProperties.
  3. All daily notes documents and monthly subfolders are created under /Day Planner/YYYY/MM/.

4. User Instructions & Workflow Guide

format_list_bulleted A1–C9 Task Prioritization & Status Codes

Tasks are categorized into Priority Groups (A = Urgent, B = Important, C = Low) with sequence numbers (1–9). Click the status box to cycle: • (Open) → ✓ (Completed) → → (Forwarded) → X (Canceled) → G/✓ (Delegated).

move_item Monthly Master Task Transfer

Open the Master Task List tab to view categorized monthly objectives (Work, Personal, Financial, Projects). Click Move to Today to assign an active [A1] priority tag and transfer it directly to today's task list.

tag Automated Monthly Indexing (#index)

Tag key meeting outcomes or decisions in your daily notes using #index [Topic] Summary. The Monthly Index automatically aggregates and links these entries chronologically.

sync 2-Way Workspace Sync

Click 2-Way Sync in the top header bar to reconcile tasks and calendar appointments. Background triggers automatically run every 5 minutes.
