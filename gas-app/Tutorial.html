school Tutorial

Short exercises that teach each feature. Each one is also an acceptance test.

How to Use This Page

Open an exercise, do what it says, then check the place it points you to. Mark Pass if you saw exactly what Pass if describes, otherwise mark Fail and type what you saw. Your marks stay in this browser. Copy results gives you a dated list to paste into a note or an issue.

  • Start every test item with its exercise number, for example DP-T01, so you can find and delete it afterwards.
  • For Gmail exercises, send yourself a new email each time, with a new subject. The hub handles each email thread once, so relabelling an old one does nothing.
  • Do the Clean up step before moving on.

Before You Start

Exercises T09 to T15 need the Gmail hub. Change these settings in the Hub Config Sheet (About › Automatic Tasks › Hub settings). If an exercise needs a setting that is off, skip it. That is a setup gap, not a failure.

Planning Your Day

T01 Add a priority task
Do
On the Daily tab, type DP-T01 Call vendor #a in the new task box and press Enter.
Look in
Today’s task list on the Daily tab, then Google Tasks.
Pass if
The task appears in the A group with a code such as A1, its title no longer shows #a, and it is in Google Tasks due today.
Clean up
Keep it for T03, then delete it in Google Tasks.
T02 Add details to a task
Do
Add the task DP-T02 Renew permit | form 7 due Friday.
Look in
The task’s sticky note icon, then the task’s details in Google Tasks.
Pass if
The title reads DP-T02 Renew permit, and both the sticky note and Google Tasks show form 7 due Friday.
Clean up
Delete the task in Google Tasks.
T03 Forward a task to tomorrow
Do
Click the status box of DP-T01 and pick Forward to tomorrow.
Look in
Tomorrow’s Daily page (use the next-day arrow).
Pass if
Tomorrow has one copy of DP-T01 Call vendor, and today’s task still shows Forwarded.
Clean up
Delete both copies in Google Tasks.
T04 Move a Master Task to today
Do
In Google Tasks, add DP-T04 Plan offsite with no date. Open the Master Tasks tab (reload if it is not there yet) and click Move to Date on it, with today’s date picked.
Look in
Today’s task list on the Daily tab.
Pass if
DP-T04 Plan offsite is on today’s list with a priority code, and you did not have to retype it.
Clean up
Delete it in Google Tasks.
T05 Plan something months ahead
Do
On the Future Planning tab, add DP-T05 Budget review in a month at least two months away.
Look in
Google Tasks.
Pass if
There is a Google Task DP-T05 Budget review due on that date, with [Future] in its details.
Clean up
Delete it in Google Tasks.

Turning Email into Tasks (Gmail Hub)

T09 Open the hub settings
Do
Go to About › Automatic Tasks › Hub settings. Click Open Hub Config Sheet, or Set up hub if it is not set up yet.
Look in
The Sheet that opens in a new tab.
Pass if
It opens on the Config tab and lists GMAIL_ROUTER, DRY_RUN, TRIAGE_BOARD and NCMMS_CORE_PILOT. Change one, reopen this Tutorial, and the Before You Start table shows the new value.
Clean up
Set any value you changed back, unless you are setting up for T10 onward.
T10 Trial run: nothing is created
Needs
GMAIL_ROUTER on, DRY_RUN on, TRIAGE_BOARD on, schedule installed.
Do
Send yourself a new email with the subject DP-T10 plus today’s date. In Gmail, apply the label 🎯/Task. Wait about 10 minutes.
Look in
The Triage tab, then Google Tasks.
Pass if
Triage shows the Trial mode banner and lists the email, and no Google Task was created.
Clean up
Nothing. The email and label can stay.
T11 Email to task with 🎯/Task
Needs
GMAIL_ROUTER on, DRY_RUN off (Triage: Review and go live), schedule installed.
Do
Send yourself a new email with the subject DP-T11 plus today’s date and apply 🎯/Task. Wait about 10 minutes, then wait another 10.
Look in
The Master Tasks tab, Google Tasks, and the Triage tab.
Pass if
Exactly one undated task DP-T11 exists, its details hold a Gmail link that opens the email, Triage shows it as Done, and the second wait created no duplicate.
Clean up
Delete the task in Google Tasks.
T12 Email to today with 🎯/Task-Today
Needs
Same as T11.
Do
Send yourself a new email DP-T12 plus today’s date and apply 🎯/Task-Today. Wait about 10 minutes and reload the app.
Look in
Today’s task list on the Daily tab.
Pass if
DP-T12 is on today’s list, with the Gmail link in its details.
Clean up
Delete the task in Google Tasks.
T13 Track a reply with 🎯/Waiting
Needs
Same as T11.
Do
Send yourself a new email DP-T13 plus today’s date and apply 🎯/Waiting. Wait about 10 minutes.
Look in
Google Tasks, and the Daily page on the follow-up date.
Pass if
A task DP-T13 exists with [Waiting] in its details, due on a follow-up date.
Clean up
Delete the task in Google Tasks.
T14 Send an email to the next Core meeting
Needs
Same as T11, plus NCMMS_CORE_PILOT on and the Core meeting’s notes Doc in the Meeting Registry tab of the Hub Config Sheet.
Do
Open Meeting Prep and note the carry-in count. Send yourself a new email DP-T14 plus today’s date and apply 🎯/Meeting/NCMMS-Core. Wait about 10 minutes, then reopen Meeting Prep.
Look in
The Meeting Prep tab, then the meeting’s notes Doc (use its link).
Pass if
The count went up by exactly one, and the Doc lists a link to the email under PREP / EMAIL CARRY-INS for the next meeting. The count matches the number of links there.
Clean up
Delete the DP-T14 line from the notes Doc.
T15 Archive and Delete from Triage
Needs
GMAIL_ROUTER and TRIAGE_BOARD on, DRY_RUN off.
Do
Send yourself two new emails, DP-T15a and DP-T15b plus today’s date, and label both 🎯/Read. Open Triage. Click Archive on DP-T15a and Delete on DP-T15b.
Look in
The Triage tab, then Gmail: the Inbox, the 🎯/Read label, and Trash.
Pass if
Both rows leave the Triage board. DP-T15a is gone from the Inbox but still under 🎯/Read. DP-T15b is in Gmail Trash.
Clean up
Delete DP-T15a in Gmail. Leave DP-T15b in Trash; Gmail empties it after 30 days.

Gmail Labels and Filters

T19 Create the Gmail labels
Do
On About, under Automatic Tasks, click Create Gmail labels.
Look in
The message next to the buttons, then the label list in Gmail (left side).
Pass if
The message names what was created (or says all labels already exist), and Gmail shows 🎯 with Task, Task-Today, Waiting, Meeting (with NCMMS-Core and NCMMS-Daily under it), Read and Review.
Clean up
Nothing to clean up; running it again creates nothing new.
T20 Suggest and create a filter
Do
Click Suggest filters, then Open the Filter Suggestions tab. Tick Create? on one row with high Precision, then click Create checked filters.
Look in
The Filter Suggestions tab, then Gmail Settings › Filters and Blocked Addresses.
Pass if
The tab lists your existing 🎯 filters and new suggestions with Caught and Wrong counts; the ticked row shows Created and a Filter id; Gmail has a new filter whose only action is applying that 🎯 label.
Clean up
Delete the new filter in Gmail settings if you do not want it.
