install_desktop Install Day Planner as Desktop App

Day Planner can be installed as a distraction-free, borderless desktop app with its own taskbar/dock icon:

desktop_windows Google Chrome (Recommended)

  1. Click the Chrome Menu (⋮) in the top-right corner.
  2. Select Save and share (or More tools) → Create shortcut...
  3. Check "Open as window" and click Create.

laptop_mac Microsoft Edge

  1. Click Edge Menu (…) → Apps → Install this site as an app.
  2. Click Install to launch in a standalone window.
