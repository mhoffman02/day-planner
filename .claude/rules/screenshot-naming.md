# Rule: Semantic Screenshot Naming

Always use short, descriptive, semantic names for all screenshot artifacts captured during visual reviews, UI testing, or bug diagnosis.

## Examples:
- `desktop_daily.png`
- `mobile_daily.png`
- `desktop_monthly.png`
- `desktop_tasks.png`
- `modal_event_edit.png`
- `search_modal.png`

## Guidelines:
- Avoid generic, verbose, or timestamped names like `ui_review_1.png` or `screenshot_20260817_120400.png`.
- Format as `<viewport>_<view_or_component>.png`.
