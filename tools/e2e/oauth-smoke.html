Stage 3 write-path + offline outbox test

To test the offline round-trip: open DevTools → Network → set throttling to "Offline", click "Add test task" (it queues to the outbox instead of failing), set Network back to "Online" (or wait for the browser's own online event), then click "Flush outbox" and confirm the task shows up via "Check outbox" going to 0 and a subsequent getDailyData fetch.
